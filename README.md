## 📌 About the Project

VoxLedger is a blockchain-based electronic voting project that combines facial verification, cryptographic techniques, and decentralized vote storage.

The proposed system aims to reduce voter impersonation, prevent duplicate voting, protect vote integrity, and provide transparent election result monitoring.

**Research publication:** This project is associated with a published research paper in IJRASET.

## ✨ Key Features

- **Voter Registration:** Registration using personal information and credentials.
- **Authentication:** Credential-based voter login.
- **Facial Verification:** Biometric identity verification.
- **Election Management:** Election dates and candidate information.
- **Secure Vote Casting:** Validation to prevent duplicate voting.
- **Blockchain Integration:** Ethereum-based vote storage using smart contracts.
- **Cryptographic Integrity:** SHA-256 hashing for vote data.
- **Result Monitoring:** Vote counting and election result generation.

*Note: Features are part of the proposed system; implementation and testing status will be documented as development progresses.*

## ⚙️ Installation and Setup

### Prerequisites

- JDK 8 or later
- Eclipse IDE
- Apache Tomcat 9
- MySQL Server
- MySQL Workbench
- Ganache
- Git

### Setup

1. Clone the repository:

```bash
git clone https://github.com/jenifer1104p/VoxLedger-Secure-eVoting.git
```

2. Import the project into Eclipse as an existing project.

3. Configure Apache Tomcat 9.

4. Create the MySQL database using the SQL scripts in the `database` directory.

5. Configure your database credentials using the environment variables described in `.env.example`.

6. Configure the required blockchain and facial verification services.

7. Run the application using Apache Tomcat.
